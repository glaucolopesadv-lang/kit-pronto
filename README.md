# Kit Pronto — atualizações

Este repositório guarda apenas os pacotes de atualização do programa **Kit Pronto**.
O próprio programa consulta este endereço pelo botão **🔄 Versão / ⬆ Atualizar**.

Não contém modelos, timbrados, dados de clientes nem configurações.
